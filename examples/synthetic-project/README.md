# Synthetic project

Parcelboard is a fictional command-line utility that sorts parcel labels. The observations are invented for repeatable review. Dates, identifiers, revisions, and receipts carry no production meaning. Evaluate cases from this directory or copy only the declared inputs to a fresh workspace.

The release fixtures share the same candidate. The second one pairs it with a successful CI run on another revision and a successful runtime check from another rollout. It uses the same digest as the expected rollout to exercise identity checks independent of artifact equality.
