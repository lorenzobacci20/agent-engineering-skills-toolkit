# Security

Use GitHub's private vulnerability reporting flow when it is available. Otherwise contact the maintainer through an existing private channel. Include the affected revision, a concise description, impact, and the smallest synthetic example that explains the issue. Keep secrets and private artifacts out of reports and public issues.

The distributed checker works on local evidence. Install skills in a scratch or project-scoped directory, inspect any added scripts before use, and use tool permissions appropriate to the task. Report any evidence that a skill or script performed an unexpected write, external request, or disclosure.
