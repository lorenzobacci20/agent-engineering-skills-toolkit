# Handoff worksheet

- **Outcome** and the part completed.
- **Anchor** with branch, commit, and whether the verification included local changes.
- **Scope** with affected entry points and local edits that existed before the session.
- **Evidence** with commands or check URLs, version/environment, outcomes, and skipped checks that matter.
- **Continuation** with the smallest actionable open step, prerequisites, and side effects.
- **Durable records** with links to updated project documentation or the owner of a pending action.

When resuming, compare the receipt against the current working tree before using it. If evidence was generated on a different commit or a different set of local changes, rerun the pertinent checks or label the record historical. If inherited edits overlap the task, isolate your change only when you can preserve both sets of work. Surface conflicts before any destructive operation.
